## 🚀 Projetos em destaque

### 📦 [StockFlow](https://github.com/Karllyson-Paula/stockflow)
Sistema de gestão de estoque desenvolvido para um negócio real de pequeno porte, em uso ativo.

- Cadastro de produtos com variantes e preço por variante
- Carrinho de saída com baixa automática de estoque
- Alerta de estoque baixo configurável por negócio
- Dashboard com busca, filtro por categoria e ordenação

**Stack:** Next.js 16 · Prisma 5 · PostgreSQL · NextAuth.js · Tailwind CSS
